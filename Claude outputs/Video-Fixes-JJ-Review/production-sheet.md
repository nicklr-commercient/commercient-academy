# Production Sheet: Commercient Partner Implementation Series

How to generate the 15 NotebookLM videos. This file is for you; don't upload it to NotebookLM.

## One-time setup

1. Create a new notebook named **Commercient Partner Implementation Series**.
2. Add all 17 source files: `00-series-bible.md`, `01-visual-brand-guide.md` and the 15 `epNN-…md` episode files. Don't upload this production sheet.
3. Generate **Episode 0 first** and watch it. If the tone, pacing or visuals are off, adjust `00-series-bible.md`, re-upload it, and regenerate before doing the rest.

## Settings for every video (keep them identical)

- **Studio → Video Overview →** customize.
- **Format:** Explainer.
- **Sources:** tick only the three files listed for that episode.
- **Visual style** (if the option appears): choose Custom and paste the text below. If Custom isn't offered, choose Classic for every video.
- **Custom topic:** paste that episode's prompt.

**Visual style text:**

```
Flat vector corporate illustration in Swiss International Typographic Style: minimalist, clean grid layouts, generous white space. Simple geometric shapes, rounded corners, consistent thin outlines, solid flat color fills; no gradients, shadows, textures, sketch lines or watercolor. Infographic diagrams, icons and flowcharts with arrows. Palette: white and pale blue #dce7f1 backgrounds, navy #1c3b60, teal #19a4d0 as the only accent, light blues #a2bedb and #789cc2, graphite #444444 text. Bold uppercase geometric sans-serif titles with wide letter spacing. No logos, mascots or photos.
```
